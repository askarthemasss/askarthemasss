### Operating principles

| # | Rule |
|---|------|
| 01 | The model is the easy part. The harness, data, and evals are the job. |
| 02 | Sit close to the problem. Ship on their data, their stack, their constraints. |
| 03 | Bound everything — steps, cost, latency, permissions. Assume the model is wrong. |
| 04 | Measure before you scale. Golden sets, traces, recall@k, unit economics. |
| 05 | Hand off a system that runs without you. |
