> **⚙️ Snake setup** — To activate the contribution snake, create `.github/workflows/snake.yml` in this repo:
> ```yaml
> name: Generate Snake
> on:
>   schedule: [{cron: "0 0 * * *"}]
>   workflow_dispatch:
> jobs:
>   snake:
>     runs-on: ubuntu-latest
>     steps:
>       - uses: Platane/snk@v3
>         with:
>           github_user_name: askarthemasss
>           outputs: |
>             dist/github-contribution-grid-snake.svg
>             dist/github-contribution-grid-snake-dark.svg?palette=github-dark
>       - uses: crazy-max/ghaction-github-pages@v3
>         with:
>           target_branch: output
>           build_dir: dist
>         env:
>           GITHUB_TOKEN: ${{ secrets.GITHUB_TOKEN }}
> ```
> Run it once manually from the **Actions** tab → the snake will appear automatically.
