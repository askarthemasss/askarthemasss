<details>
<summary><b>⚙️ One-time setup — click to expand</b></summary>

<br/>

Create these two workflow files in your `.github/workflows/` folder. Run each once from the **Actions** tab. After that they run automatically every day — no external service, GitHub serves them.

**`.github/workflows/snake.yml`** — animated contribution snake
```yaml
name: Snake Animation
on:
  schedule: [{cron: "0 0 * * *"}]
  workflow_dispatch:
jobs:
  snake:
    runs-on: ubuntu-latest
    steps:
      - uses: Platane/snk@v3
        with:
          github_user_name: askarthemasss
          outputs: |
            dist/github-contribution-grid-snake.svg
            dist/github-contribution-grid-snake-dark.svg?palette=github-dark
      - uses: crazy-max/ghaction-github-pages@v3
        with:
          target_branch: output
          build_dir: dist
        env:
          GITHUB_TOKEN: ${{ secrets.GITHUB_TOKEN }}
```

**`.github/workflows/metrics.yml`** — full stats card
```yaml
name: GitHub Metrics
on:
  schedule: [{cron: "0 0 * * *"}]
  workflow_dispatch:
jobs:
  metrics:
    runs-on: ubuntu-latest
    steps:
      - uses: lowlighter/metrics@latest
        with:
          token: ${{ secrets.METRICS_TOKEN }}
          user: askarthemasss
          template: classic
          base: header, activity, community, repositories
          plugin_languages: yes
          plugin_languages_limit: 6
          plugin_stars: yes
          plugin_stars_limit: 3
          config_timezone: Asia/Kolkata
          config_theme: dark
```

> For **metrics.yml** you also need a `METRICS_TOKEN` secret — go to **Settings → Secrets → Actions** in your repo, add a [Personal Access Token](https://github.com/settings/tokens) with `read:user` and `repo` scopes.
