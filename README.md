## 🚀 What I'm Building

### 🔗 LinkOrbit

A simple, modern link-in-bio platform built as a real product rather than a template experiment.

The project explores authentication, profiles, link management, responsive UI, and a clean product experience.

**Focus:** product engineering · UX · full-stack development · shipping fast

### 🏎️ Wasteland Rally

A browser-based, post-apocalyptic 3D racing game built with **Three.js, TypeScript, Vite, and Rapier physics**.

The world, vehicle, effects, and audio are procedurally generated with no external asset downloads.

**Focus:** WebGL · physics · procedural generation · game systems

[View Wasteland Rally →](https://github.com/askarthemasss/wasteland-rally)

### ⚙️ Kairos

An AI-assisted developer tooling project focused on automating parts of the GitHub pull-request review workflow.

**Focus:** GitHub APIs · AI-assisted code review · developer productivity
